# mind_dump

A new Flutter project.
A calm, local-first space to get thoughts out of your head and into focus.

## Run

```sh
flutter pub get
flutter run
```

MindDump is built with Flutter and Dart. Brain dumps are analyzed on-device
using simple text patterns, then tasks and history are saved locally with
`shared_preferences`. No account, backend, or AI service is used.

## What’s inside

- Brain dumps with prompts, sample thoughts, and organized analysis results
- Local task list with priority, completion, editing, and deletion
- Searchable brain dump history
- Insights calculated from saved thoughts and tasks
- Responsive Material 3 UI for web and mobile
